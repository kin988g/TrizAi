# TRIZ 智能体 - 本地部署版

一个基于TRIZ（发明问题解决理论）的智能分析助手，帮助你系统性地解决技术难题。

## 功能特性

- 🤖 **六步TRIZ分析法**：问题定义 → IFR理想解 → 矛盾识别 → 矛盾分析 → 原理推荐 → 方案生成
- 📚 **内置TRIZ知识库**：40个发明原理（含89条子原理）、39个工程参数、完整39×39矛盾矩阵
- 🏭 **行业案例库**：120条工业制造案例，按行业和部件类型打标，同行业案例优先展示
- 💬 **对话式交互**：像专家顾问一样一步步引导分析
- 🔧 **多AI后端支持**：Ollama本地模型、OpenAI兼容API、演示模式
- 💾 **本地存储**：对话历史保存在浏览器本地，隐私安全
- 📤 **导出报告**：一键导出完整分析报告
- 📱 **响应式设计**：支持桌面端和移动端

## 快速开始

### 方式一：直接打开（最简单）

1. 双击 `index.html` 文件，用浏览器打开即可使用
2. 默认使用**演示模式**（内置规则回复，无需AI服务）
3. 如需真实AI对话，点击右上角⚙️设置按钮配置AI服务

> ⚠️ 注意：直接打开文件时，部分浏览器可能限制本地AI API调用。如遇问题，请使用方式二启动本地服务器。

### 方式二：本地HTTP服务器（推荐）

#### Windows 用户

双击运行 `start.bat`，自动启动本地服务器并打开浏览器。

#### 通用方式（需要Python）

```bash
# 进入项目目录
cd triz-local

# 启动HTTP服务器（Python 3）
python -m http.server 8080

# 然后在浏览器打开
# http://localhost:8080
```

#### 使用Node.js

```bash
npx serve .
# 或
npx http-server -p 8080
```

## AI服务配置

点击右上角⚙️设置按钮，可配置以下三种AI服务：

### 1. Ollama（推荐，完全离线）

适合有本地GPU的用户，完全离线运行，数据不出本地。

```bash
# 1. 安装 Ollama: https://ollama.com
# 2. 拉取模型（推荐中文模型）
ollama pull qwen2.5:7b
# 或其他模型
ollama pull llama3.1:8b
ollama pull deepseek-r1:7b

# 3. 启动Ollama服务（默认后台运行）
# 4. 在应用设置中选择 Ollama，地址默认 http://localhost:11434/api
```

**模型推荐：**
- `qwen2.5:7b` - 通义千问，中文效果好，推荐
- `qwen2.5:14b` - 更大模型，效果更好（需要16GB+显存）
- `llama3.1:8b` - Meta开源，英文效果好
- `deepseek-r1:7b` - 深度推理模型

### 2. OpenAI 兼容 API

支持所有OpenAI兼容的API服务：

| 服务 | API地址 | 模型示例 |
|------|---------|---------|
| OpenAI | https://api.openai.com/v1 | gpt-4o-mini, gpt-4o |
| DeepSeek | https://api.deepseek.com/v1 | deepseek-chat |
| 通义千问 | https://dashscope.aliyuncs.com/compatible-mode/v1 | qwen-plus |

在设置中：
- 服务类型：选择 `OpenAI 兼容 API`
- API地址：填入上表中的地址
- API Key：填入你的密钥
- 模型名称：填入模型名

### 3. 演示模式

无需任何AI服务，使用内置的TRIZ分析规则生成回复。适合：
- 体验TRIZ分析流程
- 无网络/无GPU环境
- 学习TRIZ方法论

> 注意：演示模式的引导文案是预设的，但**原理推荐是真实计算的**——它会根据你描述中识别到的
> 工程参数（或你在矛盾矩阵面板中手动选择的参数）查询完整的Altshuller矛盾矩阵，
> 第六步的方案方向也会基于这些实际推荐的原理生成。
> 若无法识别出参数，它会如实告知并建议你手动选择，而不会编造结果。
> 需要针对具体问题做深入的自然语言分析时，仍建议配置真实AI服务。

## 使用指南

### 开始分析

1. 在输入框描述你遇到的技术难题
2. 或点击欢迎界面的示例问题快速开始
3. 智能体会按照六步分析法逐步引导

### 六步分析流程

| 步骤 | 名称 | 目标 |
|------|------|------|
| 1 | 问题定义 | 明确技术系统、功能、痛点、约束 |
| 2 | IFR分析 | 定义理想最终结果，打破思维定势 |
| 3 | 矛盾识别 | 判断技术矛盾或物理矛盾 |
| 4 | 矛盾分析 | 用矛盾矩阵或分离原理求解 |
| 5 | 原理推荐 | 推荐3-4个最相关的发明原理 |
| 6 | 方案生成 | 输出具体可操作的解决方案 |

### 使用知识库

右侧面板提供三个标签页：

- **40发明原理**：顶部可选择**所属行业**（机械加工/汽车零部件/家电结构/精密仪器），
  点击原理可查看**子原理（具体做法）**和**行业案例**，同行业案例会排在最前
- **39工程参数**：按分类浏览工程参数
- **矛盾矩阵**：选择改善参数和恶化参数，查询推荐的发明原理

> 💡 **小技巧（推荐给初次使用者）**：在"矛盾矩阵"面板中手动选好你的改善/恶化参数后，
> 对话中的第五步会**直接采用你选择的参数**去查矩阵，而不再依赖关键词猜测，
> 得到的原理推荐和第六步的方案方向都会更准确。
>
> 查询结果会明确标注来源：
> - **经典矩阵** — Altshuller矩阵中该组合的权威推荐
> - **反向组合参考** — 该方向矩阵未收录，展示的是交换改善/恶化后的结果（矩阵不对称，仅供参考）
> - **启发式，非经典矩阵** — 该组合在原始矩阵中即为空，给出的是通用建议，不是矩阵结论

## 常见问题

### Q: 直接打开HTML文件，AI调用失败怎么办？
A: 这是浏览器的CORS安全限制。请使用本地HTTP服务器方式运行（见上方"方式二"）。

### Q: Ollama调用失败怎么办？
A: 
1. 确认Ollama已安装并运行：浏览器访问 http://localhost:11434 应返回 "Ollama is running"
2. 确认模型已拉取：运行 `ollama list` 查看已安装模型
3. 检查设置中的地址是否正确：默认 `http://localhost:11434/api`

### Q: 如何更换模型？
A: 点击右上角⚙️设置，修改模型名称即可。Ollama模型需先执行 `ollama pull 模型名` 下载。

### Q: 对话记录保存在哪里？
A: 保存在浏览器的localStorage中，清除浏览器数据会丢失。重要分析建议导出报告保存。

### Q: 支持多人使用吗？
A: 本版本是单用户本地版，对话记录保存在各自浏览器中。如需多用户共享，需要搭建后端服务。

## TRIZ理论简介

TRIZ（Theory of Inventive Problem Solving，发明问题解决理论）由苏联工程师根里奇·阿奇舒勒（Genrich Altshuller）于1946年创立。通过分析数百万件专利，总结出技术系统演化的规律与创新模式。

核心工具包括：
- **40个发明原理**：解决技术矛盾的通用创新方法
- **39个工程参数**：描述技术系统特性的通用参数
- **矛盾矩阵**：根据改善/恶化参数推荐发明原理
- **四大分离原理**：解决物理矛盾（时间/空间/条件/系统层次）
- **IFR理想最终结果**：定义零代价的完美解决方案
- **物-场模型**：分析系统功能关系
- **76个标准解**：物-场模型的标准解决方案

> 说明：以上是TRIZ理论的完整工具集背景介绍。本工具目前已实现前五项（40发明原理、39工程参数、完整矛盾矩阵、四大分离原理的引导提问、IFR引导提问），**物-场模型与76个标准解尚未在工具中提供交互式查询**，六步分析法中仅通过文字引导用户自行思考物理矛盾的分离方式。
